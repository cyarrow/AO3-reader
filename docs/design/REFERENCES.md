# 閱讀器參考研究

挑選口碑好、各有長處的閱讀器，整理「可以借鑑到 AO3 Reader」的設計。

| App | 值得借鑑 | 套用到本專案 |
|---|---|---|
| **Apple Books** | 點畫面中間才出現極簡選單；「Aa」主題面板把字型＋行距＋背景組成**預設主題**（Original、Quiet、Paper、Calm…），一鍵切換 | 閱讀設定面板最上方加入「主題預設」；選單只放最常用的四個入口 |
| **Kindle** | 底部顯示「本章剩餘 X 分鐘」，比百分比更有意義；章節進度拖曳條 | 依中文閱讀速度（約 400 字/分）估算本章剩餘時間；底部選單加章節內拖曳進度條 |
| **微信讀書** | 底部面板集中亮度、字級、背景色、翻頁方式；背景色是一排色票；章節標題大而留白 | App 內亮度調整；章節標題拆成「第 N 章」小標＋標題 |
| **讀墨 Readmoo** | 繁中排版細節好：標點、段首縮排、行距寬鬆；支援直排 | 預設段首縮排、行距 1.8；直排列入之後的候選 |
| **Moon+ Reader** | 可調整的狀態列（時間、電量、頁碼）、音量鍵翻頁、點擊區自訂 | 翻頁模式保留頁首章名、頁尾時間與頁碼；捲動模式加細的頁尾狀態列 |
| **ReadEra** | 乾淨的書架與「繼續閱讀」卡片 | 首頁最上方放一張大的「繼續閱讀」卡片 |

## 共同原則
1. **內容優先**：閱讀時畫面只有文字；選單一點即出、一點即收。
2. **少即是多**：選單第一層只放 4 個入口（目錄、上一章／下一章、顯示設定）。
3. **一致的紙張世界**：App 其他畫面（首頁、搜尋）延續閱讀器的紙張色調，而不是預設的 Material 紫色。
4. **夜間友善**：深色與純黑主題要獨立調色，不是單純反轉。
