## Design Specificity
閱讀頁本身已有方向（紙張色、思源宋體、寬行距），像一本書。但首頁、搜尋、作品頁是 Material 預設樣板，換成任何 App 都成立。
最大機會：讓整個 App 共用閱讀器的「紙張世界」。

## What's Working
- 內文排版：行距 1.8、段距、段首兩字縮排、左右對齊，中文段落節奏舒服。
- 簡轉繁自動且正確，使用者幾乎感覺不到。
- 翻頁模式的頁首章名、頁尾時間與頁碼，資訊量剛好。

## Priority Issues
1. **[P1] 閱讀選單壓在文字上**：上下欄 97% 不透明但沒有分隔，底下文字透出、頂欄蓋住章名。
   修正：實心底色＋細分隔線＋輕微陰影；選單出現時內文不動。→ layout
2. **[P1] 章節標題英文前綴**：「Chapter 1: 一切都是…」佔版面又不像書。
   修正：拆成小標「第 1 章」＋標題；目錄同樣處理。→ typeset
3. **[P1] App 外框與閱讀器是兩個世界**：淡紫 Material 預設色。
   修正：關閉 dynamic color，定義暖紙色的 light/dark color scheme，主色用 AO3 暗紅。→ colorize
4. **[P2] 首頁空洞**：只有一行最近閱讀。
   修正：大張「繼續閱讀」卡片（書名、章名、進度、剩餘時間），下方其他閱讀紀錄。→ layout
5. **[P2] 捲動模式沒有進度**：沉浸時不知道讀到哪。
   修正：底部細狀態列（章名、本章進度%、時間）；選單加章節內拖曳條與「本章剩 N 分鐘」。→ clarify

## Persona Red Flags
- **睡前讀者（深色、單手）**：選單按鈕在底部，好按；但沒有 App 內亮度調整，必須拉下系統面板，會被強光打斷。
- **追連載的人**：作品頁沒有「上次讀到第幾章、何時更新」的對照。
- **第一次使用**：翻頁模式點左右翻頁不明顯。

## Minor
- 首頁「Details」文字按鈕和標題列擠在一起。
- 字型清單的預覽字串混合中英文，可只放中文。
- 設定面板很長，常用（字級、主題）應在最上面——目前已是，保留。
